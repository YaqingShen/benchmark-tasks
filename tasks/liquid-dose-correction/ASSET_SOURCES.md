# Asset and dependency sources

The task-specific geometry in `runtime/assets/` was generated by this task's Python/Blender code. No product photograph, downloaded object mesh or scanned laboratory scene is embedded. Stock, beaker and pipette shapes are simplified models based on the supplied visual references.

The following external resources are used through the prepared runtime and are not redistributed in this task folder:

| Resource | Use | Source and license |
| --- | --- | --- |
| I2RT YAM URDF and robot meshes | Two arms and parallel grippers | [I2RT Robotics](https://github.com/i2rt-robotics/i2rt), MIT. The prepared runtime vendors them with `LICENSE.i2rt` and a source commit. |
| `yam_arena` station, embodiment and primitive room | Standard robot poses, table, ground, lighting and three cameras | [yam-isaac-lab-arena](https://github.com/kairosiann/yam-isaac-lab-arena). The public wrapper repository does not declare a general license in its root or package metadata; no general redistribution license is asserted here. Use the program-provided installation. The robot assets retain their separate MIT notice. |
| YAM launchable | Prepared execution environment | [YAM-inspect-Isaac](https://github.com/ttpierson/YAM-inspect-Isaac). Its root does not declare a general license; the vendored YAM assets have a separate MIT notice. The launchable is not bundled. |
| Isaac Lab Arena 0.3.0 | Scene and environment construction | [Isaac Lab Arena](https://github.com/isaac-sim/IsaacLab-Arena), Apache-2.0. |
| Isaac Lab 17.0.2 | Physics/environment integration | [Isaac Lab](https://github.com/isaac-sim/IsaacLab), BSD-3-Clause. |
| Isaac Sim 6.1.0.0 | Simulation and rendering | [NVIDIA Isaac Sim](https://developer.nvidia.com/isaac-sim), NVIDIA proprietary software terms according to the installed package metadata. |

| Dream client 0.1.0 | Dream-1 evaluation transport | [inspect-robots-dream](https://github.com/kairosiann/inspect-robots-dream), MIT according to installed metadata. This does not license the remote model or grant API access. |

Runtime licenses are independent of task code. The absence of a general license for a wrapper is not represented as permission to redistribute it. Installed version/license metadata is preserved in `validation/runtime-versions.json`. This task does not include Isaac Sim binaries, robot meshes, model weights or credentials.
